# 📊 RideWise: Rapido Analytics Dashboard

This project is part of **OE Foundations to Data Analytics** course.

It analyzes Rapido ride data and presents insights using an interactive Excel dashboard. The project helps understand ride trends, revenue, and customer behavior through simple data visualization techniques.

---

## 📂 Project Files

* `rawDataset_rides_data.csv` → Original dataset
* `Group3_Analysed_rides_data.xlsx` → Cleaned and analyzed data
* `Group3_Cla2_PPT.pdf` → Presentation slides
* `Group3_Cla2_Report.pdf` → Detailed project report
* `README.md` → Project description

---

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Charts (Bar, Pie, Line)

---

## 📊 Features

* Total rides, revenue, and average fare analysis
* Ride demand by hour
* Revenue by service type
* Payment method distribution
* Interactive dashboard with slicers

---

## 🔍 Key Insights

* Peak ride demand occurs in morning and evening
* Bike services generate highest revenue
* Most users prefer digital payments
* Low cancellation rate shows efficient service

---

## 🎯 Conclusion

This project shows how raw data can be converted into meaningful insights using data analytics and visualization.
